# Maestro Web

The official public web portal and REST API reference for **Maestro** — the deterministic Italian language Discord bot.

---

## Live Deployment

- **Main Guide & Student Desk:** [https://kynlos.github.io/Maestro-Web/](https://kynlos.github.io/Maestro-Web/)
- **REST API Reference:** [https://kynlos.github.io/Maestro-Web/api.html](https://kynlos.github.io/Maestro-Web/api.html) (or [/api/docs.html](https://kynlos.github.io/Maestro-Web/api/docs.html))

---

## What's Included

- **Interactive Student Desk:** In-browser linguistic simulators for Italian number words, conversational clock time, syllabification & tonic accent analysis, playable word search (Crucipuzzle), suffix alterations (Alterati), subjunctive triggers (/congiuntivo), and clitic pronoun fusion (/pronomi).
- **Offline Dictionary Demo:** Instant client-side lookup and autocomplete with zero external network requests.
- **Full REST API Documentation:** Comprehensive catalog of all 56 endpoints across 11 groups with parameter tables, method badges, and structured JSON payloads.
- **Editorial Design System:** Built with Tailwind CSS CDN, Fraunces serif display, JetBrains Mono, and dual Espresso Dark / Parchment Light themes.
