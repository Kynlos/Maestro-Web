Maestro Linguistic Intelligence Platform

REST API Reference

A unified PHP API serving every feature of the Maestro Discord bot — dictionary lookups, conjugation, games, spaced-repetition decks, quizzes, student analytics, and guild management. Zero external AI dependencies. All computation is deterministic and rule-based.

◆ 56 endpoints
◆ 623,573 Italian words offline
◆ 11 endpoint groups
◆ Zero AI — rule-based engine

Base URL & Conventions

Base URL: https://yourdomain.com/api/ Route param: ?route=<endpoint> // or clean URL: /api/<endpoint> Content-Type: application/json // all responses CORS: * // open for now — lock down in production
Authentication

Most read endpoints are open. Deck, student, and guild write endpoints require a user_id or valid Discord OAuth2 session. Auth flow via /api/auth/discord/url.

Response Envelope
"ok": true, "data": { … } // success "ok": false, "error": "Message" // error

Testing Mode

The API ships with an in-memory PHP test suite at tests/test_api.php — 46 tests, ~1.4 s runtime. Testing mode bypasses HTTP output and session calls so the test runner can call multiple routes sequentially in one PHP process.
